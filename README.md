Predictive Maintenance System with Digital Twin

This repository contains the implementation of a predictive maintenance system developed as part of a master's thesis. The project demonstrates how machine learning models can be integrated with a digital twin simulation and a PLC-style inference service to detect potential machine failures and classify their causes.

The main goal of the project is to simulate a realistic industrial monitoring pipeline where sensor measurements are streamed to an AI model that evaluates the health of a machine in real time. The system combines model training, model deployment, simulation of machine data, and a graphical monitoring interface into a single workflow.

System Overview

The project is composed of several components that work together to form the predictive maintenance pipeline. Machine learning models are first trained on historical machine data. Once trained, these models are deployed through a lightweight REST inference service that mimics the behavior of an industrial PLC with embedded AI capabilities.

A digital twin simulation is then used to generate sensor measurements from a machine and stream them to the inference service. The predictions returned by the models are monitored through a desktop application that allows the user to control the entire workflow and visualize results.

The complete process therefore follows a simple sequence: models are trained, the inference service is started, the digital twin begins streaming data, and predictions are monitored through the application interface.

Dataset

The models are trained using the AI4I 2020 Predictive Maintenance Dataset, which contains simulated measurements from industrial machines. The dataset includes sensor readings such as air temperature, process temperature, rotational speed, torque, and tool wear, along with labels that indicate whether a machine failure occurred and which type of failure it was.

Two versions of the dataset are used in this project. The full dataset is used for training the machine learning models, while a smaller subset of the data is used for the digital twin simulation. This allows the simulation to stream realistic machine data without interfering with the training process.

Machine Learning Pipeline

The prediction system follows a two-stage architecture. The first stage is responsible for detecting whether a failure is likely to occur. This binary classifier outputs a simple prediction indicating whether the machine is operating normally or if a failure is expected.

If the first stage predicts that a failure will occur, a second model is used to determine the type of failure. This second model performs a multiclass classification task and identifies the likely cause of the failure. Examples include tool wear failures, heat dissipation failures, power failures, overstrain failures, and random failures.

Separating the detection and classification tasks allows the system to focus first on identifying abnormal machine behavior and then on determining the specific fault category.

PLC AI Inference Service

The trained models are deployed through a small REST service implemented using Flask. This service acts as the inference layer of the system and represents a simplified version of how machine learning could be integrated into industrial automation environments.

The service receives sensor measurements as input and returns predictions that include the failure probability, the predicted failure state, and the predicted failure type if a failure is detected. A health endpoint is also provided so that the application can check whether the models are loaded and ready for inference.

This design allows the digital twin simulation and the monitoring application to interact with the prediction models through a simple and well-defined interface.

Digital Twin Simulation

The digital twin is used to simulate sensor data generated by a machine operating in an industrial environment. Instead of connecting to real sensors, the simulation reads measurements from the dataset and sends them sequentially to the PLC inference service.

Each data point is treated as a new sensor measurement and is transmitted to the server at a fixed time interval. The inference service evaluates the data and returns predictions, which are then displayed in the monitoring interface.

To make the simulation more realistic, the predicted failure probabilities are mapped to alarm levels that resemble industrial monitoring systems. Low probabilities correspond to normal operation, intermediate values indicate warning conditions, and very high probabilities trigger critical alarms.

Desktop Application

A desktop application was developed using PySide6 to provide a graphical interface for interacting with the system. The application acts as the central controller of the predictive maintenance pipeline.

Through the interface, users can train machine learning models, start or stop the PLC inference server, run the digital twin simulation, and observe prediction results in real time. The application also displays evaluation results from the training process, such as model performance comparisons and confusion matrices.

A dedicated monitoring panel displays live predictions generated during the digital twin simulation. This panel shows the predicted failure probability, the predicted failure state, the true failure label from the dataset, the predicted failure type, and the current alarm level.

Although the application is primarily intended for experimentation and demonstration purposes, it provides a simplified representation of how predictive maintenance dashboards could be implemented in industrial environments.

Running the System

To use the system, the repository should first be cloned and the required Python packages installed. Once the environment is prepared, the machine learning models can be trained using the training script provided in the repository.

After training is complete, the PLC AI service can be started. This service loads the trained models and begins listening for incoming prediction requests. The digital twin simulation can then be executed, which will start streaming sensor measurements to the inference service.

Alternatively, the entire workflow can be controlled through the desktop application, which provides buttons for training models, starting the server, and launching the simulation.

Purpose of the Project

The system presented in this repository demonstrates how predictive maintenance techniques can be implemented using machine learning and digital twin concepts. While the implementation is simplified, it illustrates several important ideas used in modern industrial systems, including real-time inference, monitoring dashboards, and simulation-based evaluation.

The project was developed as part of a master's thesis and serves primarily as a research prototype that explores the integration of machine learning with industrial monitoring workflows.
